# keetbox

A free cybersecurity learning platform for beginners.

Built by [Asheesh Sharma](https://github.com/Asheesh-01) in public.

## What this is

KEETBOX helps beginner cybersecurity students answer three questions:

1. What is cybersecurity and is it right for me?
2. How do I learn it, and what roadmap do I follow?
3. How do I build a portfolio that proves what I know?
